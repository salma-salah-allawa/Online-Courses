# Online Courses Website

## Overview

Online Courses Website is a frontend web development project created as part of a university assignment.

The project was developed collaboratively as a team to build a simple and user-friendly website that allows students to explore and view online courses.

## Features

- Display online courses for students.
- Provide dedicated pages for course information.
- Navigate between different sections of the website.
- Use CSS animations to improve the user interface and overall experience.

## Technologies Used

- HTML
- CSS
- CSS Animations

## Project Purpose

The main goal of this project was to practice frontend web development concepts and apply HTML and CSS skills to build a functional multi-page website.

The project also provided practical experience in teamwork, organizing web pages, designing user interfaces, and applying CSS animations.
